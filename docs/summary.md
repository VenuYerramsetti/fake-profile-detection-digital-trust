# Project Summary

This project presents an early-stage system for detecting fake profiles and botnets in online social networks.

The approach focuses on embedding hidden identity information within user profile images using watermarking and steganography techniques.

The system is designed to detect identity cloning by identifying duplicate use of profile images and monitoring suspicious activity patterns.

## Core Contributions

- Identity verification using embedded data
- Detection of profile cloning attacks
- Integration of intrusion detection mechanisms

## Modern Relevance

This work aligns with current research areas such as:

- AI-generated identity fraud
- Deepfake detection
- Digital trust systems
- Responsible AI and governance

This project represents foundational work that influenced later interest in AI ethics, trust, and responsible AI systems.
