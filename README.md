# Fake Profile Detection in Social Networks

## Overview
This project explores early approaches to detecting fake profiles and botnets in online social networks using techniques such as steganography, watermarking, and intrusion detection.

## Motivation
Online social networks face increasing threats from identity cloning, fake accounts, and malicious bots. This project investigates how embedded data and behavioral analysis can be used to detect unauthorized profile duplication.

## Approach

The system combines multiple techniques:

- Image-based watermarking to embed identity information
- Steganography for hidden data encoding
- Intrusion detection to monitor suspicious activity
- Profile similarity analysis

## System Workflow

1. User uploads profile image
2. Hidden identity information is embedded using watermarking
3. System monitors duplicate usage of the same image
4. Suspicious profiles are detected and flagged
5. Alerts are generated for potential identity misuse

## Key Concepts

- Digital identity verification
- Data hiding techniques
- Social network security
- Botnet detection

## Relevance Today

Although originally developed before the rise of generative AI, this work is highly relevant to modern challenges such as:

- Deepfake-based impersonation
- AI-generated identity fraud
- Synthetic media misuse
- Digital trust and verification

## Limitations

- No machine learning-based detection
- Limited scalability
- Designed for controlled environments

## Future Work

- Extend to deepfake and synthetic media analysis
